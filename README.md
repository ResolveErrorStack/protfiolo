⚡ Getting Started

Requirements

Install:

Node.js 20+

pnpm

Git

Docker (optional)



---

Clone Repository

git clone https://github.com/ResolveErrorStack/ResolveErrorStack-Portfolio.git

cd ResolveErrorStack-Portfolio


---

Install Dependencies

pnpm install


---

Setup Environment

Create:

.env

Example:

DATABASE_URL=
AI_API_KEY=
JWT_SECRET=
NEXT_PUBLIC_API_URL=


---

Run Development

Frontend:

pnpm dev

Backend:

pnpm api


---

🧪 Testing

Run tests:

pnpm test

Build check:

pnpm build

Lint:

pnpm lint
